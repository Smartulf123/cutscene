# Third-party material in Cutscene

Generated by `tools/sync-hyperframes.mjs` from `tools/sync-map.json`. Do not edit by hand; change
the map (`thirdParty`, `targets`) and re-run the sync.

Cutscene is built on HyperFrames, an open-source framework by HeyGen (Apache-2.0). Cutscene is independent and not affiliated with HeyGen. The engine itself is the `hyperframes` npm package at the version pinned in `skills/cutscene/engine.json`; it is installed on first use and is not part of this repository. The skills listed below were rebuilt from the HyperFrames skills by `tools/sync-hyperframes.mjs`: copied, renamed and adapted for Cutscene (every adapted file carries an "Adapted from HyperFrames" header). The HyperFrames licence is the Apache License 2.0, the same licence as Cutscene (`LICENSE`).

## Loaded at run time, not bundled

- **GSAP** (GreenSock): loaded by compositions from a pinned CDN URL or provided by the engine. GSAP Standard License (https://gsap.com/standard-license), free for commercial use; not an OSI open-source licence.
- **three.js** (MIT), **Lottie** (lottie-web, MIT), **Anime.js** (MIT), **TypeGPU** (MIT): optional runtime adapters documented in cutscene-animate; loaded by a composition only when it uses them.
- **Registry blocks and components** installed with `cutscene add` are downloaded from the engine's online registry when the user asks for them; each block keeps its own licence files (for example three.js MIT, GSAP Standard License notices, OFL fonts, Poly Haven CC0 HDRIs).
- **Kokoro-82M** (Apache-2.0) voices and the engine's local transcription and cut-out models are downloaded by the engine on first use of `cutscene tts` / `cutscene transcribe` / `cutscene remove-background`, only after the user agrees (`--yes`).
- **Sound effects** (19 Pixabay files, Pixabay Content License, https://pixabay.com/service/license-summary/): not in this repository, because that licence does not allow sharing them as a standalone library. `skills/cutscene-audio/scripts/sound-engine.mjs` copies them, checksum-checked against `skills/cutscene-audio/sound/sfx/sha256.json`, from the installed engine package (`hyperframes`, which ships them) into a video project's `assets/sfx/` when a video uses them.
- **Google Fonts**: compositions may link Google Fonts at render time; families keep their own licences (mostly SIL OFL 1.1).
