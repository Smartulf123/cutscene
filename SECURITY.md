# Security policy

## Reporting a problem

Please report security problems privately through GitHub:
[Report a vulnerability](https://github.com/Smartulf123/cutscene/security/advisories/new).
Don't open a public issue for them.

Include what you found, how to reproduce it, and which version of Cutscene and which operating
system you used. You'll get a reply within a week.

## Supported versions

Only the latest release gets security fixes.

## What Cutscene protects against

[docs/security.md](docs/security.md) explains how the live preview, downloads, file paths and
voice cloning are protected, and lists the known limits.
