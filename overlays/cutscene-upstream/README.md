# Router knowledge from the engine's skills

Written for Cutscene. This folder is generated by the sync tool in `tools/` from the engine's
own router and Studio skills (credits and licence in `THIRD_PARTY.md`), adapted for Cutscene. The
`/cutscene` router (`../../SKILL.md`) reads these files on demand; they are reference knowledge,
not separate skills.

| File | What it holds |
|---|---|
| [router-guide.md](router-guide.md) | the engine router's routing table, intent layer hand-off and domain-skill loading, rewritten to Cutscene skill names |
| [studio.md](studio.md) | Studio conventions: talk before building, one scene per sub-composition, one caption track, safe zones, plan → storyboard → build |
| [references/intent-interview.md](references/intent-interview.md) | the intent layer: memory, triage, pitch round, must-haves, run shape, hand-off |
| [references/brief-contract.md](references/brief-contract.md), [references/brief-format.md](references/brief-format.md) | gate types, `flow` / `storyboard` modes, remembered defaults, the brief's shape (`.cutscene/brief.md`) |
| [references/storyboard-format.md](references/storyboard-format.md), [references/script-format.md](references/script-format.md) | `STORYBOARD.md` and `SCRIPT.md` formats used by the promo workflows |
| [references/review-loop.md](references/review-loop.md), [references/production-loop.md](references/production-loop.md) | plan pass, sketches, final preview approval; multi-scene assembly |
| [references/capability-menu.md](references/capability-menu.md), [references/pitch-round.md](references/pitch-round.md) | what can be offered to the user during intake |
| [references/frame-worker-core.md](references/frame-worker-core.md), [references/subagent-dispatch.md](references/subagent-dispatch.md) | the frame-worker brief and how workflows dispatch one sub-agent per frame |
| [references/routes/](references/routes/) | per-route intake questions (product launch, explainer, PR to video, general video, motion graphics, captions, talking-head recut) |

What Cutscene changed on the way in:

- Skill names: `/cutscene-compose`, `-animate`, `-design`, `-captions`, `-audio`, `-render`,
  `-promo`, plus Cutscene's own `-voice`, `-3d` and `-edit`.
- Removed: usage and plan checks, CLI upgrade probes, skill installs and updates, the desktop app
  hand-off, cloud rendering, publishing and feedback. Music-to-video, slideshow and Remotion
  routes are not in v1.
- The brief lives at `.cutscene/brief.md`. Remembered preferences and recipes use the scripts in
  `/cutscene-design` → `memory/`.
- Voice and transcription go to `/cutscene-voice`; sound effects and music to `/cutscene-audio`.
